# Bulutkent

2-8 yaş çocuklar için Türkçe, özgün animasyon kanalı.

Bu depo sıfırdan yeniden kuruluyor. Kurallar:
- Her video insan eliyle kontrol edilir ve onaylanır; otomatik toplu üretim yok.
- YouTube "çocuklara özel" (made for kids / COPPA) kurallarına uyulur.
- Zamanlanmış GitHub Actions iş akışı yok.

## Eski sistemden alınanlar
- `docs/`: gizlilik, şartlar ve tanıtım sayfaları (GitHub Pages)
- `brand/`, `logos/`, `banners/`: kanal markası
- `characters/`: Bulut, Pofi, Lili, Tombi, Bobo ve karakter kitabı (`bible.json`)
- `templates/fonts/`: Baloo 2 ve Nunito (SIL OFL)
