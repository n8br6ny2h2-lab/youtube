🔑 API Anahtarları

Anahtarı kutuya yapıştırın ve kaydedin. Değer ekranda veya sohbette görünmez.
  1. Bu bağlantıda projenizi seçip Etkinleştir'e basın.
  2. Credentials → Create credentials → API key.
  3. Çıkan anahtarı kopyalayıp yukarıdaki kutuya yapıştırın.
